# Set and get scdf attributes

Set and get scdf attributes

## Usage

``` r
scdf_attr(x, var = NULL)

scdf_attr(x, var) <- value

dv(scdf)

mt(scdf)

phase(scdf)
```

## Arguments

- x:

  Variable

- var:

  Attribute

- value:

  set value

- scdf:

  An [scdf](https://jazznbass.github.io/scan/reference/scdf.md) object.

## Value

Attribute value
