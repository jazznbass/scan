# Remove missing values from scdf

Removes any row with a missing value from each single-case data frame in
an scdf.

## Usage

``` r
# S3 method for class 'scdf'
na.omit(object, ...)
```

## Arguments

- object:

  A scdf.

- ...:

  not implemented yet.

## Value

A scdf object.
